# Screen Guard · 화면 잠금

![프로그램 아이콘](assets/icon.png)

[최신 실행 파일](https://github.com/henerd/AgentScreenGuard/releases/latest) · Windows 10 2004 이상 / Windows 11 · x64 · .NET Framework 4.8 이상

사람에게는 가림 화면만 보이고, AI는 그 뒤의 실제 앱을 계속 보고 조작하는 Windows용 도구입니다.

- 주 모니터에 Windows 잠금 화면과 비슷한 배경·시계·날짜 화면을 표시합니다. 클릭하거나 키를 누르면 계정·PIN 입력 화면으로 전환합니다.
- 확장 모드의 보조 모니터는 배경·시계·입력창 없이 완전히 검게 표시합니다. 복제 모드는 Windows의 화면 복제 설정을 따릅니다.
- 잠금 화면에는 프로그램 이름이나 원격 작업 상태 문구를 표시하지 않습니다.
- 가림창은 Windows의 `WDA_EXCLUDEFROMCAPTURE`로 지원되는 캡처에서 제외합니다.
- 현장 키보드와 마우스 클릭·휠 입력을 차단하고, AI가 주입한 입력은 뒤쪽 앱으로 전달합니다. 마우스 이동은 잠금 화면의 버튼을 선택할 수 있도록 허용합니다.
- 현장 키보드로 숫자 PIN을 입력하고 Enter를 누르면 해제합니다.
- 가리는 동안 절전을 억제합니다. 관리자 권한이나 추가 설치는 필요하지 않습니다.

## 사용법

1. `AgentScreenGuard.exe`를 실행하고 숫자 PIN **4~12자리**를 직접 설정합니다. 기존 PIN도 그대로 사용할 수 있습니다.
2. 처음 설정할 때 표시되는 **복구 코드**를 다른 기기나 안전한 장소에 보관하세요. 복사하거나 **다운로드에 저장**할 수 있습니다. **파일로 보관**에서는 저장 위치와 파일명을 직접 선택할 수 있으며 기본 위치는 다운로드 폴더입니다. 기존 버전 사용자는 업데이트 후 현재 PIN을 확인해 복구 코드를 발급할 수 있습니다.
3. PIN 설정 화면에 간단한 사용법이 함께 표시됩니다. **Ctrl+Alt+L**을 누르면 즉시 화면을 가립니다. 키보드·마우스·헤드셋 버튼의 눌림 상태와 관계없이 잠금을 시작합니다. 잠그기 전부터 누르고 있던 키와 마우스 버튼은 놓을 때 Windows에도 해제 신호를 전달합니다.
4. 화면을 클릭하거나 키를 누른 뒤 현장 키보드에서 **PIN → Enter**를 입력하면 해제합니다. 입력 가능한 동안 입력칸의 세로 커서가 깜빡이며, 확인 중이나 재시도 대기 중에는 커서가 사라지고 밑줄이 회색으로 바뀝니다. 숫자 키로 시작하면 첫 숫자부터 입력됩니다. 입력 중에도 AI 작업은 계속됩니다.
5. Backspace는 한 자리 삭제, Esc는 입력 초기화 또는 이전 화면으로 이동입니다. 잘못된 PIN·복구 코드에는 2~30초의 재시도 대기 시간이 적용됩니다. F1은 PIN/복구 코드 입력 전환입니다.
6. PIN 변경·배경 변경·복구 코드 재발급은 가림을 해제한 뒤 **트레이 아이콘 두 번 클릭 → 설정**에서 합니다. 설정 창의 **지금 잠그기**로도 잠글 수 있습니다.

PIN 설정 후에는 실행할 때마다 설정 창을 띄우지 않고 트레이에서 대기합니다. 자동 시작은 등록하지 않습니다.

## 업데이트

**업데이트 체크**를 누르면 공개 저장소의 GitHub Releases를 조회합니다. 최신이면 현재 버전을 표시하고, 새 버전이 있으면 파일의 SHA-256과 프로그램 버전을 확인한 뒤 교체합니다. 새 버전의 시작을 확인하지 못하면 이전 실행 파일로 복구합니다. PIN·복구 코드·배경·자동 실행 설정은 그대로 유지합니다.

Git이나 GitHub 로그인 없이 업데이트할 수 있습니다. 프로그램 폴더에 쓰기 권한이 있어야 하므로, 설치할 때 사용자가 쓸 수 있는 폴더에 압축을 풀어 실행하세요. 네트워크 오류나 검증 실패 시 기존 프로그램 파일을 교체하지 않습니다.

## 배경 변경

트레이 아이콘 **두 번 클릭** → **잠금 화면 배경 변경** → **사진 찾아보기** → **저장**을 선택합니다. JPG·PNG·BMP·GIF 이미지를 사용할 수 있습니다. 비율을 유지하면서 화면을 채우고, PIN 입력 화면에서는 흐림 효과를 적용합니다.

선택한 이미지는 `%LOCALAPPDATA%\AgentScreenGuard\background.img`에 복사하므로 원본을 이동하거나 삭제해도 배경이 유지됩니다. **Windows 배경 사용**을 선택하면 현재 Windows 바탕화면의 배경으로 돌아갑니다. 설정 창에서는 저장하기 전 미리 볼 수 있습니다.

## 보호 범위와 호환성

이 도구는 **자리 비움 중 화면 노출과 일반 키보드·마우스 조작을 막는 용도**입니다. Windows 보안 잠금과 같은 보안 경계는 아닙니다. 강제 종료·관리자 접근·Ctrl+Alt+Del·재부팅을 막지 않습니다. 같은 세션에서 실행 중인 다른 프로그램이 주입하는 입력도 허용됩니다.

Windows 10 2004 이상 / Windows 11을 대상으로 합니다. 이 PC의 Windows 11에서 실제 모니터 가림과 Codex Computer Use의 캡처·텍스트 입력·클릭을 확인했습니다. Claude 및 다른 원격 도구는 캡처·입력 방식에 따라 별도 확인이 필요합니다. 터치·펜·하드웨어 매크로 입력은 검증하지 않았습니다.

**Win+L은 Windows 잠금 기능 그대로입니다.** 이 도구를 사용할 때는 Ctrl+Alt+L을 사용하세요. 기존 자동 잠금 정책, 암호를 요구하는 화면 보호기, UAC 보안 데스크톱으로 전환되면 AI의 일반 화면 조작이 중단될 수 있습니다. 이 도구는 해당 설정을 변경하지 않습니다. 모니터 연결 변경이나 독점 전체 화면 등의 전환 순간까지 화면 보호를 보장하지는 않습니다.

## PIN 보관과 복구

PIN과 복구 코드는 원문으로 저장하지 않습니다. 각각 임의 salt와 PBKDF2-SHA256 210,000회로 검증 값을 만들고, Windows DPAPI의 현재 사용자 보호로 암호화하여 `%LOCALAPPDATA%\AgentScreenGuard\pin.dat`에 저장합니다. 네트워크 서버나 외부 패키지는 사용하지 않습니다.

PIN을 잊었을 때:

1. PIN 입력 화면의 **PIN을 잊으셨나요?**를 클릭하거나 **F1**을 누릅니다.
2. 보관한 복구 코드를 현장 키보드로 입력하고 Enter를 누릅니다. 코드의 하이픈과 공백은 입력하지 않아도 됩니다.
3. 가림이 해제되고 새 PIN 설정 창이 열립니다. 기존 PIN 없이 새 PIN을 정할 수 있습니다.
4. 새 PIN을 저장하면 복구 코드도 새로 발급합니다. 이전 코드는 사용할 수 없으므로 새 코드를 다시 보관하세요. PIN 재설정을 취소하면 기존 PIN과 복구 코드는 유지됩니다.

복구 코드는 발급할 때만 표시하며, 다시 확인할 수 없습니다. 가림 해제 상태에서 트레이 아이콘을 **두 번 클릭 → 복구 코드 발급 / 재발급**을 선택하고 현재 PIN을 확인하면 새 코드를 받을 수 있습니다. 재발급한 즉시 이전 코드는 무효가 됩니다. 일반적인 PIN 변경은 기존 복구 코드를 유지합니다.

**저장할 때 ‘파일이 없습니다’라는 메시지가 나오는 경우:** 이 PC에서는 Windows의 제어된 폴더 액세스가 프로그램의 문서 폴더 쓰기를 차단한 기록이 확인되었습니다. 복구 코드 창의 **다운로드에 저장**을 사용하세요. 다운로드 폴더에 날짜·시간이 포함된 새 파일을 만들고 저장된 경로를 표시합니다. 다른 보호된 폴더를 선택하면 Windows에서 저장을 거부할 수 있습니다.

복구 코드까지 잊었거나 프로그램에 오류가 생기면 **Ctrl+Alt+Del → 작업 관리자 → `AgentScreenGuard.exe` 종료**로 가림과 입력 차단을 해제할 수 있습니다. 종료 후 위 PIN 파일을 삭제하고 다시 실행하면 새 PIN을 설정할 수 있습니다. 이 복구 가능성이 Windows 보안 잠금과의 차이이기도 합니다.

## 빌드와 검증

`build.ps1`은 Windows에 포함된 .NET Framework C# 컴파일러로 실행 파일을 생성합니다. `release.ps1`은 `dist`에 실행 파일·SHA-256·배포 ZIP을 만듭니다. 외부 NuGet 패키지는 사용하지 않습니다. `tools/create-icon.ps1`로 ICO와 미리보기 PNG를 다시 만들 수 있습니다.

새 버전 배포는 `AppInfo.cs`의 버전을 올리고 커밋한 뒤, 같은 버전의 `v1.0.1` 형식 태그를 푸시하면 됩니다. `.github/workflows/release.yml`이 Windows 빌드와 업데이트 검증을 수행하고 GitHub Release에 파일을 올립니다. 소스에는 사용자 PIN·복구 코드·배경 이미지를 포함하지 않습니다.

`verify/build.ps1`으로 별도 검증 도구를 빌드할 수 있습니다. `verify/SmokeTest.exe`는 15초 뒤 화면을 가리고 65초 뒤 자동으로 해제합니다. 테스트용 앱의 입력란과 버튼으로 AI 조작을 확인합니다. 다른 검증 모드는 다음과 같습니다.

- `--input-only`: 현장 입력 형식의 훅 콜백을 호출하여 입력 차단·오류 PIN·4자리 PIN 해제·복구 화면 전환 검사
- `--release-only`: 검증 창을 활성화한 뒤 좌우 Alt·Ctrl·Shift와 일반 키를 누른 채 잠그고, 키를 놓았을 때 Windows 눌림 상태가 해제되는지 검사. 현장 입력 차단과 주입 입력 전달도 확인하며, 테스트용 키는 종료 시 정리합니다.
- `--recovery-only`: 복구 코드로 가림을 해제하고 기존 PIN 없이 재설정 창이 열리는지 검사
- `--data-only`: 기존 파일 호환·PIN/복구 코드 저장·재발급·배경 이미지 복사 및 복원 검사
- `--render`: 잠금·PIN·복구 화면 미리보기 PNG 생성
- `--export-ui`: 가상 코드로 실제 저장 창의 새 파일 생성을 검사하고 검증 파일을 정리
- `--metadata-only`: 버전 비교·파일 검증·아이콘·별도 테스트 키를 통한 자동 실행 등록/해제 검사
- `--settings-only`: 숨김 실행 후 설정 창 표시·재요청·배경 설정 소유 창·종료 메뉴 복원 검사
- `--network-only`: 실제 공개 릴리스 조회·다운로드·검증 검사

`verify/update-tests.ps1`은 별도 검증용 실행 파일을 사용하여 실제 파일 교체·재시작, 시작 실패 시 이전 버전 복구, 변조 파일 거부를 검사합니다. 사용 중인 프로그램과 PIN 파일은 변경하지 않습니다.

실제 물리 키보드 입력 자체는 사용자가 확인해야 합니다. 검증 도구는 운영 PIN 파일을 만들거나 수정하지 않습니다. 테스트용 PIN·복구 코드는 별도 프로세스에서만 사용하며, 실제 프로그램에는 기본 PIN이나 하드코딩된 해제 암호가 없습니다. 검증 결과는 `verify` 폴더의 각 `*-verification.log`에 있습니다.
